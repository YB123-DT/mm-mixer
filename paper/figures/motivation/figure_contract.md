# 动机场景与 AMM 图的证据范围

制图沿用本项目的 Python 工作流；只使用已有标注、视频和实现，不启动训练。

## 图 1：相同话语、不同情绪

- 结论：MELD 中同一说话人说出的相同当前话语，可以对应不同的情绪标注。
- 证据：原始 CSV 的 Utterance、Speaker、Emotion、Dialogue_ID、Utterance_ID，以及对应视频帧。
- 当前布局：三个真实片段上下排列，单栏宽 84 mm、高 72 mm；原始画面放左侧，真实标签、样本 ID 和音频包络放右侧。宽幅并列图保留为 v003 历史资产。
- 选择规则：优先同一说话人、完全相同的当前话语、不同标签；人工检查画面中说话人是否可见，不能把其他人物的表情当作目标说话人的表情。
- 限制：这是任务现象，不能证明 AMM 改进了这些样例。当前话语相同也不意味着历史增强的文本输入向量相同。
- 不将静帧当作完整表情过程，不由画面猜测声学线索；标签是数据集标注。

## 图 2：并行学习投影与分轴混合

- 结论：AMM 将模态分支表示展开成多个学习投影，并分别沿投影、模态、通道轴组织交互。
- 证据：MELD 和 IEMOCAP 实现中的 split、MixerBlock、均值聚合。
- 输入：经过前置融合的模态分支表示，不能画成未经交互的原始模态特征。
- 事实：三模态共享 Linear(256, 6×256)，等价于六组不同的学习投影；两个块交替使用 S→M 和 M→S 顺序；随后对 S 求均值。
- 模态路由：所有投影、通道位置共享静态 Linear(3,3)，不是每个视角动态选择模态权重。
- 假设：多个学习投影可能使同一输入的不同判别线索更容易参与交互；示意图不能把语义、语气、表情等名称指定给某个学习投影。
- 非事实：恢复时序、增加观测信息、视角正交或独立、六个视角分别具有固定语义。

## 导出与核对

- 当前场景图宽 84 mm，AMM 图宽 180 mm，英文图中文字；PNG 供预览，PDF/SVG 用于论文，SVG 保留可编辑文字。最终 PDF 放在 `paper/` 根目录。
- 保留原始图像比例；不合成或修改表情，不添加虚构模型预测。
- 保存样例信息、源文件哈希、帧号、截取时间、选择说明和可重跑脚本。
- 真实样例只支撑任务动机；AMM 价值需 S=1/多投影及分轴消融等公平对照。

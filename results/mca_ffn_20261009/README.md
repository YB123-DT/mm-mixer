## 分析规则

按同种子计算AMM增益：

- 有MCA时：Full − no_mixer。
- 无MCA时：no_cross_attention − both_off。
- 交互差：上述前者减后者；负值表示AMM在无MCA时增益更大。三种子仅描述均值和样本标准差，不凭正负直接断言功能冗余或统计显著。

FFN报告WF1、ACC、参数量与默认1536的同种子差；减小FFN同时改变容量，不将分数差自动归因于正则化。保留不利或无差异结果。

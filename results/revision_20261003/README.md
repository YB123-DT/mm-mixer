# 三种子补充实验结果

训练与分类指标核验已完成：24 种配置 × 2 个数据集 × 3 个种子，共 144 个位置，
包括 119 次新训练和 25 次通过正式协议与产物验证的历史结果复用，无缺失组。
效率测试仍在等待空闲 GPU，尚无耗时、吞吐量或峰值显存结论。

- [完整汇总](analysis.md)：WF1、ACC、Macro-F1、同种子差值、各类别 F1 和混淆矩阵。
- [机器可读结果](analysis.json)：逐种子指标、来源路径、验证状态及汇总数据。
- [来源与文件哈希](provenance.json)，[运行记录](../../EXPERIMENT_RUN_20261003.md)。

## 协议

保留既定 `strict_peak_test_wf1`：每次运行按测试集 WF1 选择轮次。这是 test-peak
结果，不是验证集选轮次后的独立测试结果。未根据本次结果调整参数或选择报告种子。
IEMOCAP 使用 seeds `2025, 2066, 2118`；MELD 使用 `2025, 2028, 2069`。
下面为 WF1 百分数，均值 ± 样本标准差（ddof=1），每组 n=3；差值单位为百分点。
历史 README 中四种子的汇总采用不同种子集合及标准差口径，不与本表混用。

## 当前结果支持的判断

- **AMM 整体增益较小。** Full 相比去掉 AMM，均值仅高 0.14225 / 0.05350 个百分点
  （IEMOCAP / MELD）；不能据此写成大幅提升。
- **EPIRC 的正增益尚未得到支持。** 去掉后分别高 0.02984 / 0.00119 个百分点；
  IEMOCAP 为两个种子提高、一个下降，MELD 为两个微增、一个相同。
  用普通 MLP 替换 EPIRC 的分数下降，不能抵消直接删除 EPIRC 的这一结果。
- **CubeMLP-style 在 MELD 的 WF1 与 Full 基本持平。** 均值仅低 0.00148 个百分点；
  四舍五入后相同不代表预测或其他指标完全相同。
- **两级门控的联合收益依赖数据集。** 同时删除两级门控在 IEMOCAP 下降约 0.60
  个百分点，在 MELD 三个种子均提高，平均高 0.09934 个百分点。
- **视图设置和辅助损失有更一致的方向证据。** S=1、去掉视图轴混合、去掉辅助损失，
  均在两个数据集各自的三个种子上低于 Full，但效应大小不同。

这些是当前协议下的描述性比较，未进行显著性检验。结果不支持将所有组件表述为
普遍必要，也不能仅凭三个种子的均值差异断言统计显著。

## 核验与剩余工作

队列完成检查包含正式 epoch 预算、配置、源码/数据/产物哈希及 checkpoint 严格重载；
合并分析重新检查身份、完成状态、预测与指标哈希，并从预测重算指标。
本地再次独立重算 48 组的均值、样本标准差和同种子差值，与导出报告一致。

剩余 8 次效率测量覆盖两数据集的 Full、MLP、Attention、CubeMLP-style（seed 2025），
由现有持久控制器等待同一张健康空闲 GPU 后执行。分类结果已归档；论文 TeX/PDF 尚未填入本批分数。

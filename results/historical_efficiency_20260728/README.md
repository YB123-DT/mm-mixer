## 比较时必须保留的差异

- 原始汇总器把 `batch_size_dialogues` 和 `batch_size` 统一写成 32，丢失了单位。
  已核对 DialogueRNN、CSS、Ada2I 为对话批，MM-Mixer 为话语批；不能写成所有模型都以
  32 条话语一批运行。其他模型的批单位尚未在本次恢复中逐一核查，CSV 明确标记。
- 记录仅给出 GPU 型号，没有充分记录同一物理 GPU、并发占用及统一 CPU 线程条件。
  原始计时波动亦保留在 `raw/` 中。
- 各模型采用各自已运行版本和输入特征；旧 MM-Mixer 使用 IEMOCAP seed2118、
  MELD seed2069 的 checkpoint，不能将旧耗时直接归属于本轮 seed2025 的新计时任务。
- 本次仅恢复和检查已有记录，不改主稿 TeX/PDF，不把旧结果与新测量混为同一批实验。

## 这些记录可以支持的描述

历史记录中 MM-Mixer 的下游前向耗时高于 SDT 和 CSS。因此，论文参数量较小的事实
不能用来推出推理更快，也不宜声称对所有基线有运行时间优势。正式的速度优劣结论
仍须限定测量条件，并明确系统输入和批处理差异。

按论文保留的三位小数参数值计算，MM-Mixer 相对 SDT/CSS 的参数降幅分别为
IEMOCAP 92.0% / 87.4%、MELD 91.1% / 88.6%。这些是参数降幅，不是速度提升比例。
